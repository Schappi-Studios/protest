THE SCHOOL IS OBSTRUCTING INDEPENDENT LEARNING

It is reasonable for a school to restrict AI tools, and that appears to be what has mostly happened—except Microsoft Copilot remains available. Leaving aside, for now, the question of why Copilot was chosen over other, arguably more capable alternatives, there is a separate problem: Claude Code was blocked too.

Claude Code is not primarily a tool for writing essays, generating images, or completing ordinary school assignments. It is a programming tool designed to help users work with code. St Leo’s does not teach the kind of coding Claude Code is used for—in fact, it does not currently teach coding at all.

That matters because one of the strongest reasons for restricting AI at school is preventing cheating. But if there is no coding subject or coding work to cheat on, then Claude Code cannot realistically be used to cheat in the area it is designed for.

I am not arguing here that every AI service should automatically be made available. I am arguing that Claude Code serves a legitimate purpose for students who independently learn programming, while posing little or no academic-integrity risk to a school that does not teach programming. Blocking it therefore does not prevent cheating; it simply makes independent learning more difficult.
